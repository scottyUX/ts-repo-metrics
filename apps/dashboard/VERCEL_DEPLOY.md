# Vercel dashboard deploy — retired

Analyze **requires a git binary**. The zipball + GitHub REST fallback that existed for Vercel serverless is **removed**. Do not deploy Analyze to Vercel.

**Supported hosts:** local development and [Railway](../../RAILWAY_DEPLOY.md) (Docker image includes `git`).

OAuth, Supabase, and environment-variable names are documented in [`RAILWAY_DEPLOY.md`](../../RAILWAY_DEPLOY.md). Historical Vercel project settings are obsolete; keep this file only as a pointer so old links do not 404.
